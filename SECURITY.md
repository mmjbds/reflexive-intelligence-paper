# Security Policy

Do not open public issues containing credentials, private drafts, restricted review material, customer data, private logs, exploit chains, or de-anonymizing information.

Report sensitive findings privately to `373743743@qq.com`. In the first message, send only the affected public component, impact category, and a safe way to request details.

This route does not authorize testing third-party systems, production services, private infrastructure, customer environments, or accounts.
