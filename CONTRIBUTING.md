# Contributing

This repository accepts narrow source, citation, accessibility, and evidence-boundary repairs for the published paper.

Pull requests must identify the exact location, distinguish build-only changes from scientific changes, provide the compile command and result, update `CHECKSUMS.sha256` when tracked artifacts change, and cite the source and reuse basis for external material.

Do not include private drafts, review correspondence, credentials, customer data, or unpublished research. Scientific claim changes require supporting evidence and must remain consistent with `CLAIM_BOUNDARY.md` and the DOI record.
